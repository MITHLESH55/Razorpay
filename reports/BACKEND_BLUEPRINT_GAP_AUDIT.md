## Detailed Gap Summary & Execution Strategy

1. **Top-Level Route Alignment**: Map all Blueprint-specified top-level `/risk/...` paths (`/risk/queue`, `/risk/cases`, `/risk/cases/{case_id}/verification`, `/risk/cases/{case_id}/decision`, `/risk/cases/{case_id}/action-preview`, `/risk/cases/{case_id}/approve`, `/risk/cases/{case_id}/reject`, `/risk/cases/{case_id}/edit`, `/risk/cases/{case_id}/simulate`, `/risk/cases/{case_id}/outcome`, `/risk/cases/{case_id}/audit`, `/risk/audit`, `/risk/cases/{case_id}/feedback`, `/risk/governance`, `/ready`, `/live`) directly on the FastAPI application while preserving full backward compatibility with `/risk/score`, `/risk/investigate`, and existing `/api/v2/ops/...` routes.
2. **Case Orchestrator Service**: Build `CaseOrchestrator` in `src/ops/case_orchestrator.py` to seamlessly link `InvestigationAgent`, `PaymentGraphEngine`, `PolicyEngine`, `OutcomeVerifier`, `HumanApprovalGate`, `CounterfactualSimulator`, `AuditTrail`, `FeedbackStore`, and `CaseManager` into a unified lifecycle control plane.
3. **Structured Schemas & Error Contract**: Implement `src/api/schema_control_plane.py` with typed Pydantic models for Queue, GraphSnapshot, EvidenceBundle, VerificationResult, DecisionResult, ActionPreview, SimulationResult, OutcomeResult, AuditEvent, FeedbackRecord, SystemHealth, and GovernanceState. Implement consistent JSON error models (HTTP 400, 401, 403, 404, 409, 422, 429, 503).
4. **State Machine & Concurrency**: Enforce state machine transitions (`CREATED` -> `INVESTIGATING` -> `EVIDENCE_READY` -> `VERIFIED` -> `RECOMMENDED` -> `PENDING_APPROVAL` -> `APPROVED` / `EDITED` / `REJECTED` -> `SIMULATED` -> `VERIFIED_OUTCOME` -> `CLOSED`) with optimistic concurrency checks (`expected_version` -> 409 Conflict) and idempotency key mapping.
5. **Testing & Validation**: Implement unit and integration tests covering queue filtering, state transitions, idempotency, optimistic locking, RBAC, PIT enforcement, leakage boundaries, evidence grounding, golden cases, and an HTTP end-to-end integration test.
6. **Documentation & Demo**: Create `docs/API_CONTRACT.md`, `docs/BACKEND_ARCHITECTURE.md`, `docs/BACKEND_BLUEPRINT_TRACEABILITY.md`, and `scripts/run_demo.py`.
