## 2. API Contract Verification Rules
1. **Zero Hardcoded Benchmark Values**: Frontend components must exclusively bind to the `/risk/evaluation` and `/risk/governance` API payloads.
2. **Safe Degradation**: When `/ready` returns `DEGRADED` or graph engine is unavailable, the UI clearly displays "Relationship intelligence unavailable" without manufacturing synthetic graph topology.
3. **Shadow Mode Enforcement**: When `shadow_mode_enabled: true`, the persistent banner appears across all views and consequential buttons switch to "Simulate Action" mode.
4. **Optimistic Locking**: Approvals pass `expected_version`; HTTP 409 triggers conflict notification and state re-fetch.
