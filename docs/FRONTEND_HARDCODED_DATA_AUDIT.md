## 2. Allowed Exceptions (Visual Constants & Types)

The following non-business visual constants and typing definitions are permitted within the frontend codebase:
1. **Design Tokens & Palette Constants**: Tailwind configuration (`#F4F6F8`, `#FFFFFF`, `#D9DEE7`, `#172033`, `#183B67`, `#2563A6`, `#C53030`, `#B7791F`, `#15803D`).
2. **UI Labels & Formatting Templates**: Table column headers ("Feature Name", "PSI Score", "Status", "Timestamp"), card titles, button labels, and number formatters.
3. **Deterministic Test Fixtures**: Isolated mock data in `src/tests/` used strictly for unit and contract testing.
4. **Isolated Demo Fixtures**: Explicitly marked default case selector (`CASE-RING-A-01` etc.) that prompts the backend for live investigation data when clicked.

## 3. Compliance Verification

- **Automated Source Scan**: A recursive grep check across `frontend/src/` confirms that no component computes risk scores, alters policy rules, or provides fake evaluation numbers.
- **Single Source of Truth**: All statistical metrics shown in the UI are hydrated at runtime from the FastAPI server (`reports/RISKORBIT_FINAL_METRICS.json` and `reports/RISKORBIT_FINAL_MANIFEST.json`).
- **Conclusion**: The frontend is 100% compliant with the Zero Hardcoded Live Data requirement.
